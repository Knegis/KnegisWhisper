# Security policy

Please report suspected vulnerabilities privately through GitHub:
[report a vulnerability](https://github.com/Knegis/KnegisWhisper/security/advisories/new), or open the repository's **Security** tab
and choose **Report a vulnerability**. Only you and the maintainers can see the
report. It needs a GitHub account.

Do not file a public issue for an unfixed vulnerability, and do not put
credentials, private recordings or exploit details in a public issue.

See [the detailed security policy](docs/SECURITY.md) for credential handling,
network boundaries, updater signing and the threat model.
