# Security policy

Please report suspected vulnerabilities privately to a repository maintainer
through an existing private channel. Do not put credentials, private recordings
or exploit details in a public issue.

This repository is currently private. GitHub private vulnerability reporting is
not available for this repository.
Before a public launch, enable private vulnerability reporting and verify the
report form before advertising it as the primary contact route.

See [the detailed security policy](docs/SECURITY.md) for credential handling,
network boundaries, updater signing and the threat model.
